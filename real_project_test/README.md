# 真实项目测试：任务管理Web应用
# Real Project Test: Task Management Web Application

## 🎯 项目描述 (Project Description)

这是一个用于测试 Claude Code + AceFlow MCP Server 集成的真实项目。

我们将构建一个现代化的任务管理Web应用，包含以下功能：

- 用户注册和登录
- 任务创建、编辑、删除
- 任务状态管理（待办/进行中/已完成）
- 任务分类和标签
- 响应式UI设计
- RESTful API

## 🛠 技术栈 (Tech Stack)

- **Frontend**: React.js + TypeScript + Tailwind CSS
- **Backend**: Node.js + Express.js + TypeScript
- **Database**: SQLite (开发环境)
- **Testing**: Jest + React Testing Library
- **Build Tools**: Vite

## 📋 测试目标 (Testing Goals)

1. 使用AceFlow MCP Server的完整工作流
2. 验证双向AI-MCP协作功能
3. 测试4个核心MCP工具的实际应用
4. 验证Claude Code集成效果
