```bash

# 2. 执行数据库迁移脚本
mysql -h prod-db -u root -p myapp < migrations/v1.2.0_schema.sql

# 3. 验证迁移结果

```

#### 步骤2: 代码部署

```bash
# 1. 拉取最新代码
git clone -b release/v1.2.0 https://github.com/example/myapp.git
cd myapp

# 2. 构建Docker镜像
docker build -t myapp:v1.2.0 .

# 3. 推送到镜像仓库
docker push registry.example.com/myapp:v1.2.0

# 4. 更新Kubernetes部署(滚动更新)
kubectl set image deployment/myapp myapp=registry.example.com/myapp:v1.2.0

# 5. 验证部署状态
kubectl rollout status deployment/myapp
```

## 5. 回滚方案

### 5.1 回滚触发条件

以下情况需要立即执行回滚:
- ❌ 核心功能无法使用
- ❌ 错误率超过5%持续5分钟
- ❌ 响应时间超过1秒持续5分钟
- ❌ 出现数据丢失或损坏
- ❌ 出现严重安全漏洞

### 5.2 回滚步骤

#### 快速回滚(代码层)

```bash
# 1. 回滚Kubernetes部署到上一个版本
kubectl rollout undo deployment/myapp

# 2. 验证回滚状态
kubectl rollout status deployment/myapp

# 3. 验证服务可用性
curl https://prod.example.com/health

# 预计耗时: 5分钟
```

#### 完整回滚(包含数据库)

```bash
# 1. 停止应用服务
kubectl scale deployment/myapp --replicas=0

# 2. 恢复数据库备份
mysql -h prod-db -u root -p myapp < backup_20251106_020000.sql

# 3. 回滚代码部署
kubectl rollout undo deployment/myapp

# 4. 启动应用服务
kubectl scale deployment/myapp --replicas=3

# 5. 全链路验证
./scripts/smoke_test.sh prod.example.com

# 预计耗时: 15分钟
```
