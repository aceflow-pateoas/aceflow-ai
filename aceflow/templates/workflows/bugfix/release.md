# 发布说明阶段 (Release Notes)

## 检查清单 (Checklist)

### 必须完成 (Required)

- [ ] **代码已合并**
  修复代码已合并到主分支

- [ ] **CHANGELOG已更新**
  在CHANGELOG.md中记录此次修复

- [ ] **Issue已关闭**
  关联的Bug Issue已标记为已修复

- [ ] **版本号已更新**
  根据语义化版本规范更新版本号（通常是patch版本）

- [ ] **发布说明已编写**
  说明修复了什么问题、影响范围、升级建议

### 可选项 (Optional)

- [ ] **用户通知已发送**
  通知受影响的用户已修复

- [ ] **文档已更新**
  如果Bug涉及文档错误，更新相关文档

- [ ] **监控已配置**
  添加监控指标，防止问题再次出现

## 输出物 (Deliverables)

1. **合并记录**（Git commit/merge记录）
2. **CHANGELOG条目**
3. **发布说明**（Release Notes）
4. **版本标签**（Git tag）
5. **用户通知**（如果需要）

## CHANGELOG 格式示例

```markdown
## [1.2.3] - 2025-01-17

### Fixed
- 修复了用户登录时偶现的会话失效问题 (#123)
  - 问题：在高并发场景下，部分用户会话被意外清除
  - 影响：约5%的登录请求受影响
  - 修复：优化了会话存储的并发控制逻辑
  - 相关Issue: #123
```

## 版本号规范 (Semantic Versioning)

- **Patch版本** (1.2.3 → 1.2.4): Bug修复，向后兼容
- **Minor版本** (1.2.0 → 1.3.0): 新功能，向后兼容
- **Major版本** (1.0.0 → 2.0.0): 破坏性变更

Bug修复通常使用 **Patch版本**。
