# 问题分析阶段 (Problem Analysis)

## 检查清单 (Checklist)

### 必须完成 (Required)

- [ ] **Bug已复现**
  能够稳定复现问题，记录复现步骤

- [ ] **影响范围已评估**
  明确影响的功能模块、用户群体、严重程度

- [ ] **错误信息已收集**
  日志、错误堆栈、截图、用户反馈等

- [ ] **环境信息已记录**
  系统版本、浏览器/客户端版本、数据库版本等

- [ ] **优先级已确定**
  P0/P1/P2/P3，是否需要紧急修复

### 可选项 (Optional)

- [ ] **相关Issue已查阅**
  检查是否有类似的历史问题

- [ ] **临时规避方案已提供**
  给用户提供临时解决方法（如果可能）

## 输出物 (Deliverables)

1. **Bug复现步骤**（详细的操作步骤）
2. **环境信息**（版本、配置等）
3. **错误日志/截图**
4. **影响评估报告**（严重程度、影响范围）
5. **优先级标签**（P0/P1/P2/P3）

## 完成标准 (Completion Criteria)

- 能够稳定复现问题
- 收集到足够的诊断信息
- 明确了问题的影响范围和优先级
