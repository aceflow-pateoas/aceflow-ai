## 文档编写最佳实践

### 1. 结构清晰
- 使用标题层级组织内容
- 每个小节聚焦单一主题
- 提供目录导航

### 2. 语言简洁
- 使用简单明了的语言
- 避免过于技术化的术语（或提供解释）
- 使用主动语态

### 3. 示例丰富
- 每个概念配有代码示例
- 示例可运行、可复制
- 从简单到复杂渐进

### 4. 视觉辅助
- 复杂概念用图表说明
- 操作步骤配有截图
- 使用高亮和格式化

## 代码示例规范

```python
# ✅ 好的示例：简洁、可运行、有注释

from aceflow import WorkflowEngine

# 创建工作流引擎
engine = WorkflowEngine(project_id="my_project")

# 启动功能开发工作项
result = engine.start_work_item(
    type=WorkflowType.FEATURE,
    title="用户登录功能"
)

print(f"工作项ID: {result['work_item_id']}")
```
